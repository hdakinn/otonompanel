# OtonomPanel (Beta) — Home Assistant uygulama deposu

Bu depo **OtonomPanel** uygulamasını içerir: Home Assistant evinizi tarayıp tablet için hazır, sade bir ev paneli kurar.
Lite ücretsiz ve süresizdir; Pro yakında. OtonomPanel şu anda **beta** sürümündedir.

## Kurulum
**[Home Assistant'a ekle](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fhdakinn%2Fotonompanel)**

1. Yukarıdaki bağlantıya basın ve **Ekle**'ye dokunun. Elle eklemek için: Home Assistant'ta **Ayarlar → Uygulamalar →
   Uygulama mağazası** → sağ üstteki menü → **Depolar**, bu deponun adresini ekleyin: `https://github.com/hdakinn/otonompanel`
2. Mağazada **OtonomPanel (Beta)** uygulamasını açın, **Kurulum**'a sonra **Başlat**'a basın.
3. Kenar çubuğundaki **OtonomPanel (Beta)**'yı açın; kurulum sihirbazı karşılar.

Tablet bağlantısı ve QR kodu için: **OtonomPanel-Kurulum.html** dosyasını (bu depoda) bilgisayarınıza indirip açın.
Uygulama mağazası olmayan kurulumlar (Home Assistant Container, Core) için Windows kurulum programı
**OtonomPanel-Kurulum.exe**, [Sürümler](https://github.com/hdakinn/otonompanel/releases) sayfasındadır.

Gereksinim: Home Assistant 2025.12 ya da üstü, Home Assistant OS ya da Supervised.
